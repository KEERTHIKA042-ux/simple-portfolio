Personal Portfolio Website

This project is a simple and elegant personal portfolio website built using HTML and CSS.
It includes two main sections — a Home page that introduces me and highlights my background, and a Contact page where visitors can get in touch.

🖥️ Overview

The website is designed with a clean and minimal layout to ensure easy navigation and a pleasant user experience.
It reflects my design sense, creativity, and attention to detail while keeping things lightweight and fast-loading.

✨ Features

Modern and minimalist design

Fully responsive layout for desktop and mobile

Smooth navigation between pages

Organized and easy-to-edit code structure

🛠️ Technologies Used

HTML5 – for structuring the content

CSS3 – for styling, layout, and basic responsiveness
